# UI 設計與介面討論規範（Layout Comparison Protocol）

1. **介面原型先行**：
   每當使用者提出新的頁面需求、導覽結構調整或互動流程討論時，**嚴禁直接修改專案主程式檔案**。
2. **強制產出 Layout Comparison 互動預覽**：
   必須先產出一個可即時預覽的 `Layout Comparison` 互動原型（並排呈現原來的版面與使用者提出的設計差異的手機/桌面視窗框架），讓使用者確認改動方向。
3. **確認後才進入實作**：
   產出預覽後必須暫停並詢問使用者偏好的方案編號或組合方式，待使用者明確核准後，才將選定設計轉化為正式專案程式碼。
